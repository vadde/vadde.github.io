# Appa Rao Vadde — Interactive Resume

This repository hosts the source code for my interactive, single-file HTML resume.

## 🌐 Live Deployments

This repository is connected to **two** hosting platforms. Pushing to the `master` branch of this repository will automatically trigger deployments to both:

1. **GitHub Pages**: [vadde.github.io](https://vadde.github.io)
2. **Netlify**: [appavadde.netlify.app](https://appavadde.netlify.app)

> **Note**: Because both platforms are wired to this single source of truth, any changes made to `index.html` or the `audio/` directory here must be pushed to GitHub to reflect on both live URLs simultaneously.

## 📁 Structure

- `index.html`: The fully self-contained HTML/CSS/JS resume file.
- `audio/`: Contains the background soundtrack referenced by the HTML.
- `README.md`: This file.
